  • 本地运行：config.cfg → [azure] → client_id / client_secret / tenant_id

客户端密码到期后的更新步骤

  1. 打开 Microsoft Entra 管理中心 → 应用注册 → Microsoft_Graph_API_CNMAS_New。
  2. 进入“证书和密码”→“新客户端密码”，在旧密码到期前创建新密码。
  3. 立即复制新密码的 Value（不是 Secret ID）。
  4. 更新 GitHub 仓库 Secret CLIENT_SECRET。
  5. 更新本地 config.cfg 的 [azure].client_secret。
  6. 测试邮件发送和 MS365 / OneDrive for Business 工作流。
  7. 确认新密码正常后，再删除旧密码；建议新旧密码短期重叠。

通常无需修改 CLIENT_ID 或 TENANT_ID；Personal OneDrive 的 ONEDRIVE_CLIENT_ID / refresh token 与此客户端密码无关。到期日期请在 Entra Portal 查看。
